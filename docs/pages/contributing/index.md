# How to contribute

LimaNix is three repositories that ship together. Open an issue or a pull request in the one your change belongs to; the [organization guide](https://github.com/limanix/.github/blob/main/CONTRIBUTING.md) covers issues, release labels and the license for all of them.

| Repository                                    | Holds                                                                   | Guide                                |
| --------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| [client](https://github.com/limanix/client)   | `limanix`, the command on the Mac                                       | [The client](/contributing/client)   |
| [lmx](https://github.com/limanix/lmx)         | `lmx` and its daemon, inside every VM                                   | [The lmx command](/contributing/lmx) |
| [modules](https://github.com/limanix/modules) | The catalog of shells, toolchains and modules, its themes and base disk | [The catalog](/contributing/catalog) |

Each guide on these pages is the repository's own `CONTRIBUTING.md` on its `main` branch.
